# Aniket Sehgal - Personal Portfolio

A modern, responsive portfolio website built with Bootstrap 5 and custom CSS animations.

## Features

### ✅ Completed Requirements:
- **Custom CSS Animations**: Multiple `@keyframes` animations including fade-in, floating, rotating, gradient shifts, and hover effects
- **CSS-only Loader**: Implemented both spinner and pulsing dots loader with accessibility features
- **Semantic HTML**: Proper use of `<header>`, `<nav>`, `<main>`, `<footer>`
- **Accessibility**: Respects `prefers-reduced-motion` with fallbacks for all animations
- **Custom CSS**: Extensive customizations in `custom.css` and `custom-animations.css`

### ✨ Enhanced Features:
- **Animated Gradient Background**: Smooth gradient shift animation covering entire background
- **Decorative CSS Shapes**: Floating circles, rotating triangles, squares, and hexagons
- **Wave Animation**: SVG wave effect with continuous motion
- **Advanced Hover Effects**: 3D card transforms, gradient buttons with shine effects, glowing borders
- **Interactive Elements**: Image zoom containers, text reveal animations, shimmer effects

### 🎨 Design Elements:
- Dark theme with accent color (#22e7a1)
- Responsive design for all screen sizes
- Custom scrollbar styling
- Animated statistics counters
- Portfolio filtering with smooth transitions
